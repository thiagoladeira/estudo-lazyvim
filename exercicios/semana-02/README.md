# Semana 2 — Desafio de navegação

Abra `nvim` na raiz de `estudo-lazyvim` e cronometre cada tarefa (meta: < 3 s cada):

1. Abrir `projetos/ts/src/calc.ts` com `<leader><space>`.
2. Achar onde aparece a palavra `subtrair` em todo o projeto com `<leader>/`.
3. Abrir `PLANO.md` em split vertical (`<leader>|`) e voltar com `<C-h>`.
4. Alternar entre os 3 últimos buffers com `<S-h>` / `<S-l>`; fechar um com `<leader>bd`.
5. No neo-tree (`<leader>e`): criar `exercicios/semana-02/rascunho.md` (`a`), renomear (`r`) e apagar (`d`).
6. Descobrir com `<leader>sk` qual atalho abre o "Lazy".
