# Semana 4 — LSP no dia a dia

Use **apenas** recursos do LSP (sem `:%s`!):

1. `pedidos.py` / `pedidos.ts`: renomeie `p`, `lst`, `f` para nomes descritivos com `<leader>cr`.
2. Use `gr` para ver todos os usos de `calc_tot` / `calcTot` antes de renomear.
3. Corrija os erros apontados pelos diagnósticos (`]d`, `<leader>cd`, `<leader>xx`).
4. Use `<leader>ca` para adicionar o import que falta.
5. Use `K` sobre funções da biblioteca padrão para ler a documentação.
